# ⚙️ ফেজ ৪ — ইঞ্জিন আপগ্রেড (আধুনিক ক্রোলার, SPA, প্রিভিউ)

> **অগ্রাধিকার:** মিডিয়াম-উচ্চ — এটাই প্রজেক্টকে "wget wrapper" থেকে **আসল ডাউনলোডার** এ রূপ দেবে।
> **সময়-খরচ (আনুমানিক):** ১–২ সপ্তাহ (ধাপে ধাপে ভাগ করা যায়)।
> **পূর্বশর্ত:** ফেজ ১ (সুরক্ষা) অবশ্যই শেষ। নতুন নির্ভরতা: `playwright`, `got`, `cheerio`, `adm-zip`।

---

## উদ্দেশ্য

wget একা আধুনিক ওয়েব (React/Next/Vue SPA, CSS `@import`/`url()` চেইন, CDN অ্যাসেট) সঠিকভাবে ধরতে পারে না। এই ফেজে **দুই-ইঞ্জিন সিস্টেম** — সরল সাইটে দ্রুত wget, জটিল/SPA সাইটে JS-ভিত্তিক ক্রোলার — এবং ডাউনলোড-পরবর্তী অভিজ্ঞতা (প্রিভিউ, ফাইল ব্রাউজ, রিপোর্ট) যোগ করা।

---

## কাজ তালিকা

### ৪.১ ইঞ্জিন-আর্কিটেকচার: মোড সিলেক্টর

- [ ] নতুন `engine/` মডিউল — সব ইঞ্জিনের জন্য এক ইন্টারফেস: `start(url, options, onUpdate)` → cancel-করা যায় এমন হ্যান্ডেল ফেরত
- [ ] **Mode A — wget fast-path (ডিফল্ট):** স্ট্যাটিক/ক্লাসিক সাইটে আজকের proven পথ
- [ ] **Mode B — JS-ক্রোলার:** সাইটে SPA-র চিহ্ন দেখা মাত্র (HTML-এ JS-bundle + কম কনটেন্ট, framework meta) ক্রোলার শাখায় যাওয়া
- [ ] UI-তে ইঞ্জিন-সিলেক্টর: "Auto (প্রস্তাবিত)" / "Fast (wget)" / "Full (JavaScript rendered)"
- [ ] দুই শাখার আউটপুট একই ফরম্যাটে (zip) — উপরের স্তরে কোনো ভাঙা নেই

### ৪.২ JS-ক্রোলার শাখা (Playwright-ভিত্তিক)

**কেন Playwright:** ব্রাউজারে পেজ রেন্ডার করে তারপর DOM ধরে — SPA-ও সম্পূর্ণ আসে; `fetch`/XHR-এর বাস্তব নেটওয়ার্ক-কলও ইন্টারসেপ্ট করা যায়।

- [ ] `playwright` (Chromium) ইনস্টল
- [ ] ক্রোল: entry-URL রেন্ডার → `a href` সংগ্রহ → একই-সাইট ফিল্টার → প্রতি URL-এ রেন্ডার + সেভ
- [ ] নেটওয়ার্ক-ইন্টারসেপ্ট: `page.on('request')` — প্রতিটি রিসোর্স (JS/CSS/ফন্ট/XHR) ডিস্কে সেভ
- [ ] সীমা: কোটা, পেজ-সীমা (ডিফল্ট সর্বোচ্চ ২০০ পেজ), timeout — ফেজ ১-এর নিয়ম এখানেও প্রযোজ্য

### ৪.৩ CSS/JS লিংক-রিরাইট (সম্পূর্ণ অফলাইন সাইট)

**সমস্যা:** ডাউনলোড হওয়া সাইটের CSS/JS-এ absolute URL (CDN/মূল ডোমেইন) থাকলে ইন্টারনেট ছাড়া খোলা যায় না।

- [ ] `.css`: `url(...)` ও `@import` — লোকাল-পথে প্রতিস্থাপন
- [ ] `.html`: `link href`, `script src`, `img src`, `source`, `video/audio src`, `meta og:image`
- [ ] `.js`: নিরাপদ-প্যাটার্নে (fetch/axios/new URL string) সীমিত প্রতিস্থাপন — আগে CSS/HTML, পরে সাবধানে JS
- [ ] রিলেটিভ-পাথ collision রোধে গাছ-ভিত্তিক নামকরণ
- [ ] টেস্ট: জিপ খুলে `file://` দিয়ে পেজ সত্যিই খোলে কি না

### ৪.৪ প্রিভিউ মোড (জিপ ডাউনলোডের আগে দেখা)

- [ ] সার্ভারে zip `downloads/preview/<jobId>/`-এ unzip (`adm-zip`/`yauzl`)
- [ ] এক্সপ্রেস static: `/preview/:jobId/` থেকে সাইট রেন্ডার
- [ ] "প্রিভিউ দেখুন" বাটন — নতুন ট্যাবে preview ইনডেক্স খোলা
- [ ] প্রিভিউ ফোল্ডারও TTL-ক্লিনারের অধীন (জিপের একই খাতা)

### ৪.৫ ফাইল এক্সপ্লোরার (জিপের ভেতরে ব্রাউজ)

- [ ] `/api/preview/files/:jobId` — ফোল্ডার-বাস্তব ফাইল-লিস্ট (path, size, mime)
- [ ] UI: সরল ট্রি/ব্রেডক্রাম্ব ব্রাউজ; ফাইল-ক্লিকে প্রিভিউ বা সরাসরি ডাউনলোড
- [ ] জিপে কী কী অন্তর্ভুক্ত তার এক-নজরে হিসাব

### ৪.৬ ডাউনলোড-রিপোর্ট

- [ ] প্রতি জবের `report.json` — কত ফাইল, কত byte, সময়, ব্লকড/ব্যর্থ-সংখ্যা, ইঞ্জিন, ত্রুটি-লগের সার
- [ ] "রিপোর্ট দেখুন" → সরল HTML প্রতিবেদন (PDF/MD এক্সপোর্ট ফেজ ৫-এ)
- [ ] রিপোর্টও TTL-ক্লিনারের অধীন
